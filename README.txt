IMPORTANT:
For Android to install this as a true home-screen app, these files must be hosted together on an HTTPS website.
Opening index.html directly from Downloads will let you use the app, but Android/Chrome may not offer full PWA installation.

Once hosted:
1. Open the website in Chrome on Android.
2. Tap the three dots.
3. Choose "Add to Home screen" or "Install app".
4. The Green Eyed Girl icon will appear on the Home screen.

The app stores sale data locally on that device/browser. Use Download Backup regularly.
